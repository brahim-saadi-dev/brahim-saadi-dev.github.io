Currency Converter

Python · tkinter

A small desktop app that converts between eight currencies. Type an amount, pick two currencies, and press Convert. It has a Swap button, shows a clear message when the input isn't a number, and keeps its exchange rates in one simple table that is easy to update. You can try a browser version of it right here.

Live demo: a JavaScript version of the Python app. Rates are fixed examples, not live market rates.

def convert(amount, from_currency, to_currency):
    # go through US dollars first, then to the target currency
    amount_in_usd = amount / rates[from_currency]
    return amount_in_usd * rates[to_currency]

Library Database

SQL · SQLite

A small database for a library, with three linked tables: books, members and loans. It comes with sample data and five queries that answer real questions: which books are on loan, which are overdue and by how many days, the most borrowed books, members who never borrowed, and which books are available today. Bank Account System


C++


A menu-driven bank program built around an Account class. Balances are private, so money can only change through deposit() and withdraw(), which refuse invalid amounts and overdrafts. You can create accounts, deposit, withdraw and list every account. Try it right here.
























Live demo: a JavaScript version of the C++ program. Accounts are kept in memory, so they reset when you reload the page.




bool withdraw(double amount)
{
    if (amount <= 0 || amount > balance)
        return false;
    balance -= amount;
    return true;
}
